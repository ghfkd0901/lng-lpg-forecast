# 산업용 LNG · LPG 요금 전망

배포: https://lng-lpg-forecast-dse.streamlit.app/

국제 에너지 가격과 환율로 **한국가스공사 도매원가(→ 대성에너지 산업용 요금)**와 **LPG 공급가격**을 최대 24개월 앞까지 전망하는 Streamlit 앱입니다.

## 화면

| 페이지 | 내용 |
|---|---|
| 📊 요금 전망 | LNG·LPG 비교, LNG 도매원가, LPG 요금, 시나리오 계산기, 모델 설명 |
| 🔄 데이터 업데이트 | **최신 데이터로 갱신** 버튼 하나로 모든 지표를 수집해 시트에 반영 |

## 데이터

### 저장 위치 (Google Sheets)

| 시트 | 탭 | 내용 |
|---|---|---|
| 에너지 지표 시트 | `Master_Data` | 월별 WTI · 브렌트유 · 헨리허브 · JKM · TTF · 환율 · 두바이유 · JCC |

### 수집 방법 (`data_update.py`, `jcc_estat.py`)

| 지표 | 출처 | 계산 |
|---|---|---|
| 브렌트유 · WTI · 헨리허브 · JKM · TTF | Yahoo Finance 선물 (`BZ=F`, `CL=F`, `NG=F`, `JKM=F`, `TTF=F`) | 일별 종가의 월평균 |
| 환율 (원/달러) | Yahoo Finance `KRW=X` | 일별 종가의 월평균 |
| JCC | 일본 재무성 무역통계, e-Stat API | 아래 참고 |

**JCC 계산**

1. e-Stat `getStatsList`로 「普通貿易統計 貿易統計_全国分 概況品別国別表 輸入」 통계표를 찾습니다(연도별로 표가 나뉘며, 공개일이 늦은 표가 같은 달을 덮어씀 → 확정·확보치 우선).
2. 概況品 `30301 原油及び粗油`(API 코드 `30301000`)의 월별 수입 금액(千円)·수량(KL)을 국가별로 합산합니다.
3. `JCC($/배럴) = 금액×1000 ÷ 수량(KL) ÷ 6.28981(배럴/KL) ÷ 월평균 엔/달러(Yahoo JPY=X)`
4. 10~300 $/배럴을 벗어나면 단위 오류로 보고 중단합니다.

- 재무성 발표가 **다음 달 하순**이라 보통 1~2개월 전 달까지 나옵니다(예: 9월분은 10월 말).
- 공식 JCC는 세관 고시환율 기준이라, 시장 월평균 환율을 쓰는 계산값과 1% 안팎 차이가 날 수 있습니다.

**갱신 규칙**

- 최근 3개월(`REFRESH_MONTHS`)은 매번 다시 가져와 덮어씁니다 — 이번 달은 월중 평균이고, JCC는 속보→확보 수정이 있기 때문입니다.
- 바뀐 값만 시트에 쓰고, 바뀐 목록(월·지표·기존·새 값)을 화면에 보여줍니다.
- 한쪽(Yahoo / e-Stat) 수집이 실패해도 나머지는 반영하고 경고를 띄웁니다.

## 모델 (`app.py`)

| 연료 | 예측 대상 | 입력 변수 (반영 시차) |
|---|---|---|
| LNG | 가스공사 도매원가 (원료비 + 가스공사 공급비용) | JCC 4개월 · JKM 2개월 · 환율 1개월 |
| LPG | SK가스 가정·상업용 공급가격 (원/MJ, VAT 별도) | 브렌트유 1개월 · 환율 1개월 |

- 시차는 시계열 교차검증으로 오차가 가장 작은 값을 골랐습니다.
- 선형회귀 · 랜덤포레스트 · 그래디언트 부스팅 · XGBoost **4개 모델 평균**을 예상요금으로 씁니다.
- LNG 산업용 요금 = 예측 도매원가 + 대성에너지 공급비용(요금비교 시트 최신값).
- 학습 기간은 2015-01부터, 옵션으로 요금 급등 구간(2022.8 ~ 2023.3)을 제외할 수 있습니다.
- 학습한 모델은 `models/`에 저장하고, 시트 데이터가 바뀔 때만 다시 학습합니다.

### 미래 입력값

- 이미 발표된 달은 실적을 씁니다.
- **JCC** 미발표 달: `JCC ≈ a + b × 1개월 전 브렌트유` 선형회귀(상관계수 약 0.98)로 추정.
- 그 밖의 지표: Holt 추세 예측(과거 최저값의 절반 ~ 최고값의 2배로 제한).
- 입력값이 모두 실적이면 ‘확정 지표’, 하나라도 추정이면 ‘추정 지표’로 표시합니다.

### 예상 범위

- `예상요금 ± 2σ × √(최근 실적 이후 개월 수)`, σ = 과거 요금 월간 변동폭의 표준편차.
- 그래프에서는 기본으로 숨겨져 있고, 범례의 ‘예상 범위’를 누르면 표시됩니다. 표의 하단·상단 열에는 항상 나옵니다.

### 실적 처리

- 요금비교 시트에서 빈칸이나 0인 달은 아직 실적이 없는 것으로 보고, 그 달부터 전망으로 채웁니다.

